# 《顶不住了》开发说明

## 动态素材系统

动态反馈集中在 `src/game/effects/` 与 `src/game/config/effectsConfig.ts`。

- `animation.ts` 提供实体抖动、闪白、屏幕震动、漂字、爆炸、血条追血动画等通用函数。
- `feedback.ts` 负责把“敌人受击、敌人死亡、塔开火、炸弹爆炸”等游戏事件组合成表现效果。
- `Effect` 是 Canvas 特效对象，统一由现有游戏循环更新和销毁，不额外创建 DOM 节点。
- 敌人和塔只新增视觉状态字段，例如 `visualOffset`、`flashTimer`、`attackTimer`，不改变原有数值结算。

已接入的反馈：

- 普通敌人受击：抖动、闪白、伤害数字、小血条黄条延迟追血。
- Boss：更强受击抖动、顶部血条、低血量闪烁、阶段怒气闪。
- 塔攻击：前摇压缩、炮口朝向、后坐力、枪口火光和不同塔的程序化特效。
- 炸弹：扩散爆炸、烟雾残留、屏幕轻震、范围内敌人同时反馈。
- 基地受击、Boss 登场、爆炸：统一走 `ScreenShake`，多次触发取最大强度，结束后恢复原点。
- Boss 登场：暂停刷怪约 2.5 秒，暗屏、入口警告圈、大字提示、震屏，然后恢复流程。

## 特效调试

打开 `?debugEffects=1` 或在游戏中按 `D` 切换特效调试。开启后可用快捷键：

- `1` 测试敌人受击
- `2` 测试塔攻击
- `3` 测试爆炸
- `4` 测试屏幕震动
- `5` 测试 Boss 出场
- `6` 测试暴击数字
- `7` 测试血条减少

新增效果参数优先放在 `effectsConfig.ts`，避免在业务系统中硬编码节奏和强度。
